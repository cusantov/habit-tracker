# Трекер привычек

Одностраничное веб-приложение для ежедневных привычек: добавляешь привычку, отмечаешь выполнение за день, видишь прогресс за неделю. Данные хранятся в браузере (`localStorage`), сервера нет.

**Демо:** https://cusantov.github.io/habit-tracker/

## Возможности

- Добавление привычки с проверками: пустое название, дубликат и название длиннее 50 символов не принимаются
- Отметка «выполнено сегодня» и её снятие, выполненные привычки зачёркнуты и отмечены зелёной галочкой
- Счётчик «Выполнено: X из Y» в футере
- Сохранение в `localStorage` и восстановление после перезагрузки
- Сброс отметок при смене даты, история за прошлые дни сохраняется
- Прогресс за неделю: 7 квадратов за последние 7 дней и серия дней подряд
- Удаление с возможностью отменить
- Светлая и тёмная тема
- Экспорт и импорт данных в JSON
- Сортировка перетаскиванием (мышью, пальцем или стрелками с клавиатуры)
- Напоминание через Notification API
- Адаптивная вёрстка от 320 до 1920 px

## Технологии

HTML, CSS3 (Flexbox), JavaScript (ES6+) без фреймворков и библиотек. Иконки — собственные SVG.

## Структура

```
index.html   — разметка: шапка, форма, список, футер, шаблон карточки
style.css    — стили, темы, анимации, адаптив
script.js    — логика: привычки, хранилище, сброс по дате, экспорт/импорт, напоминания
```

## Данные

Ключи в `localStorage`:

| Ключ | Что хранит |
|---|---|
| `habitflow_data` | массив привычек |
| `habitflow_lastVisit` | дата последнего входа, нужна для сброса отметок |
| `habitflow_theme` | выбранная тема |
| `habitflow_reminder` | настройки напоминания |

Формат привычки:

```json
{
  "id": 1716892800000,
  "title": "Зарядка",
  "completedDates": ["2024-05-24", "2024-05-25"]
}
```

## Безопасность

Пользовательский ввод вставляется в страницу только через `textContent`, `innerHTML` не используется. Это защищает от XSS.

## Запуск

Открыть `index.html` в браузере или перейти по ссылке на демо. Напоминания работают только по `https://` или на `localhost`.
